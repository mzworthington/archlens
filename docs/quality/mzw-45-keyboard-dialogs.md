# Keyboard dialogs (MZW-45)

Surfaces: startup chooser, Pending Draft Changes (`DiffMenu`), collab name, collab share, Resilience panel.

| Quality                    | Decision | Why                                                                                                                                                                                                                                                                                                   |
| -------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Accessibility              | Apply    | Each surface has an accessible name, Tab stays inside while it is open, and Escape leaves. Axe blocks serious and critical WCAG 2.x AA issues on the chooser, pending draft changes, share dialog, join dialog and Resilience panel. A side panel yields Tab and Escape while another dialog is open. |
| Browser E2E                | Skip     | No new product journey. Keyboard leave and names are in the a11y Playwright spec and unit tests.                                                                                                                                                                                                      |
| Security                   | Skip     | These surfaces do not add a trust boundary. Room secrets and share links stay as they are.                                                                                                                                                                                                            |
| Load / performance         | Skip     | No latency SLO. Focus trapping is local key handling.                                                                                                                                                                                                                                                 |
| TraceLens full-page audit  | Skip     | Out of scope for this story. Follow up only if Resilience stays green.                                                                                                                                                                                                                                |
| Site-wide contrast rewrite | Skip     | `color-contrast` and `scrollable-region-focusable` stay on the existing axe baseline. This story does not add new suppressions.                                                                                                                                                                       |
