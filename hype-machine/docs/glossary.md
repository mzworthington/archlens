# Glossary

| Term | Meaning |
|------|---------|
| **HypeSession** | One recorded set with synced streams, features, and metadata |
| **HypeScore** | Interpretable 0–1 crowd-energy estimate from acoustic + kinetic layers |
| **HypePeak** | Sustained rise above a rolling baseline |
| **DJAction** | Timestamped mixer/control event (`drop`, `eq_kill`, `blend`, …) |
| **PatternCard** | Hypothesis that an action class precedes hype rises, with support/confidence |
| **Room mic** | Audience-facing audio — the ground truth for crowd response |
| **Session pack** | Folder with `session.json`, `features.json`, optional `actions.json` + media |
